# Ebooks gratuitos — Semana 01: El mundo relacional

> Libros de acceso libre (dominio público, licencia abierta o capítulos gratuitos)
> relevantes para los temas de esta semana.

---

## 📘 Database Design (Adrienne Watt & Nelson Eng)

- **Enlace:** <https://opentextbc.ca/dbdesign01/>
- **Formato:** HTML / PDF descargable
- **Licencia:** Creative Commons BY 4.0
- **Por qué leerlo:** introducción sólida al modelo relacional, entidades, atributos
  y tipos de datos. Los capítulos 1–4 cubren exactamente los temas de esta semana.
- **Capítulos recomendados para semana 01:** 1, 2 y 3

---

## 📘 SQL for Web Nerds (Philip Greenspun)

- **Enlace:** <https://philip.greenspun.com/sql/>
- **Formato:** HTML
- **Licencia:** Libre para uso educativo
- **Por qué leerlo:** perspectiva práctica y directa de SQL y bases de datos relacionales.
  Escrito por un ingeniero del MIT con ejemplos del mundo real.
- **Capítulos recomendados para semana 01:** Introduction, Data Modeling

---

## 📘 Documentación oficial de PostgreSQL 16 (capítulos introductorios)

- **Enlace:** <https://www.postgresql.org/docs/16/tutorial.html>
- **Formato:** HTML
- **Licencia:** PostgreSQL License (libre)
- **Por qué leerlo:** el tutorial oficial cubre la instalación, primeras consultas
  y los tipos de datos fundamentales. Es la referencia más confiable disponible.
- **Capítulos recomendados para semana 01:**
  - Part I: Tutorial (capítulos 1–3)
  - Chapter 8: Data Types (referencia completa de tipos)

---

## 📘 The Manga Guide to Databases (No Starch Press — preview)

- **Enlace:** <https://nostarch.com/mg_databases.htm>
- **Formato:** Preview de capítulos en la web
- **Por qué leerlo:** si eres visual y prefieres aprender con historietas.
  Cubre el modelo relacional, SQL básico y normalización de forma amena.
  El libro completo no es gratuito, pero los capítulos de muestra son suficientes
  para esta semana.
