## ▶️ Intro to Database Systems — CMU 15-445 (Lecture 01)

- **Enlace:** <https://www.youtube.com/watch?v=vdPALZ-GCfI>
- **Duración:** ~75 min
- **Idioma:** Inglés
- **Para qué sirve:** la primera clase del curso de bases de datos de Carnegie Mellon.
  Andy Pavlo explica qué problema resuelven las bases de datos, la historia del modelo
  relacional y por qué Codd fue un genio. Nivel universitario riguroso.
- **Recomendado para:** estudiantes que quieren profundidad conceptual.
