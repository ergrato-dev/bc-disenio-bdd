# Semana 01 — El mundo relacional

> Entiende el modelo relacional antes de escribir una sola línea de SQL

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- ✅ Distinguir los tipos de SGBD (relacional, documental, columnar) y cuándo usar cada uno
- ✅ Instalar y configurar PostgreSQL 16+ con Docker en tu equipo local
- ✅ Crear tu primera base de datos y conectarte desde pgAdmin y DBeaver
- ✅ Ejecutar sentencias `SELECT` básicas e interpretar el resultado

## 📋 Prerequisitos

- [ ] Conocimientos básicos de computación
- [ ] Docker instalado en tu equipo
