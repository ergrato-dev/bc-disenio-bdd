## Notas de uso

- **SQL for Web Nerds** — lectura clásica y directa; cubre SELECT, JOINs y NULL con ejemplos reales.
- **SQLZoo** — práctica interactiva en el navegador; ideal para reforzar SELECT y GROUP BY con datos reales.
- **Mode SQL Tutorial** — muy bien estructurado para principiantes; cubre exactamente los temas de esta semana.
- Los previews de O'Reilly cubren los primeros capítulos completos de forma gratuita.
