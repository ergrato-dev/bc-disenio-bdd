# Semana 02 — Fundamentos SQL de consulta

> Domina las bases del lenguaje que todo diseñador de datos debe hablar

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- ✅ Escribir consultas `SELECT` con filtros `WHERE`, ordenamiento y paginación
- ✅ Combinar tablas con `INNER JOIN`, `LEFT JOIN` y `RIGHT JOIN`
- ✅ Comprender el comportamiento de `NULL` y los operadores de comparación
- ✅ Aplicar funciones de agregación: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`
