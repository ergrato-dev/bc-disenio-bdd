# Semana 03 — ER Básico

> Captura la realidad del negocio antes de pensar en tablas

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- ✅ Identificar entidades, atributos y relaciones en un dominio de negocio
- ✅ Diferenciar tipos de atributos: simples, compuestos, derivados e identificadores
- ✅ Determinar la cardinalidad (1:1, 1:N, N:M) entre entidades
- ✅ Crear diagramas ER con notación Crow's Foot usando draw.io

## 📋 Prerequisitos

- [ ] Semana 02 — Consultas SQL básicas
- [ ] Comprender qué es una tabla relacional
