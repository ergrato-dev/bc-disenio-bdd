# Libros Gratuitos — Semana 04: ER Intermedio

## Libros recomendados

### 1. Database Design for Mere Mortals (3rd ed.) — Michael J. Hernandez
- **Capítulos relevantes:** 9 (Establishing Table Relationships), 10 (Refining the Table Structures)
- **Acceso gratuito:** Disponible en [Open Library (préstamo)](https://openlibrary.org/works/OL25440W)
- **Relevancia:** Capítulo 10 explica cómo manejar atributos multivaluados en el proceso de refinamiento. Capítulo 9 cubre los distintos tipos de relaciones incluyendo relaciones ternarias.

### 2. Database System Concepts (7th ed.) — Silberschatz, Korth, Sudarshan
- **Capítulos relevantes:** 6.5 (Weak Entity Sets), 6.6 (Extended E-R Features), 6.7 (Reduction to Relational Schemas)
- **Acceso gratuito (6th ed.):** [db-book.com — slides y recursos públicos](https://www.db-book.com/slides-dir/index.html)
- **Relevancia:** La sección 6.5 es la referencia académica estándar para entidades débiles. La 6.6 cubre entidades asociativas bajo el nombre "aggregation".

### 3. Fundamentals of Database Systems (7th ed.) — Ramez Elmasri, Shamkant Navathe
- **Capítulos relevantes:** 7 (More Complex Data Modeling — Specialization, Generalization, and Aggregation), 8 (The Enhanced Entity-Relationship Model)
- **Acceso gratuito:** Capítulos de muestra en [Pearson Higher Ed](https://www.pearson.com/en-us/subject-catalog/p/fundamentals-of-database-systems/P200000003551/9780137502523)
- **Relevancia:** Este libro usa el término "weak entity" de manera exhaustiva y tiene figuras claras de relaciones de identificación (doble rectángulo y doble diamante). Ideal para complementar los SVGs de la semana.

### 4. Learning SQL (3rd ed.) — Alan Beaulieu
- **Capítulos relevantes:** 13 (Indexes and Constraints), Apéndice B (Entity-Relationship Diagram)
- **Acceso gratuito:** [O'Reilly Free Trial](https://www.oreilly.com/library/view/learning-sql-3rd/9781492057604/) / [Internet Archive](https://archive.org/search?query=learning+sql+beaulieu)
- **Relevancia:** El apéndice B explica cómo las relaciones N:M se traducen a tablas intermedias en SQL real. Complementa perfectamente el concepto de entidad asociativa.
