# Ebooks y Libros Gratuitos — Semana 05: ER Avanzado

## Libros recomendados (acceso libre)

### 1. An Introduction to Database Systems — C.J. Date (excerpts)

| Campo | Detalle |
|---|---|
| **Autor** | C.J. Date |
| **Relevancia** | Capítulos sobre el modelo relacional, jerarquías y restricciones de integridad |
| **Idioma** | 🇬🇧 Inglés |
| **Acceso** | Fragmentos en Archive.org |
| **URL** | <https://archive.org/search?query=database+systems+date> |

El libro de C.J. Date es el texto fundacional del modelo relacional. Para esta semana,
son especialmente relevantes los capítulos sobre restricciones de integridad y
transformación de modelos conceptuales.

---

### 2. PostgreSQL Documentation — Chapter: Inheritance

| Campo | Detalle |
|---|---|
| **Autor** | PostgreSQL Global Development Group |
| **Relevancia** | Describe la herencia de tablas nativa de PostgreSQL (diferente a CTI) |
| **Idioma** | 🇬🇧 Inglés |
| **Acceso** | Gratuito online |
| **URL** | <https://www.postgresql.org/docs/16/ddl-inherit.html> |

> ⚠️ **Nota importante:** PostgreSQL tiene una herencia de tablas propia (`INHERITS`)
> que difiere del patrón CTI del bootcamp. Leer para entender las diferencias y por
> qué CTI manual es preferible en la mayoría de casos de producción.

---

### 3. Fundamentals of Database Systems — Elmasri & Navathe (OpenAccess excerpts)

| Campo | Detalle |
|---|---|
| **Autores** | Ramez Elmasri, Shamkant B. Navathe |
| **Relevancia** | Referencia académica estándar para ER extendido (EER): especialización, generalización, restricciones |
| **Idioma** | 🇬🇧 Inglés |
| **Acceso** | Fragmentos en ResearchGate y Archive.org |
| **URL** | <https://archive.org/search?query=fundamentals+database+systems+elmasri> |

El capítulo sobre el **Enhanced Entity-Relationship (EER)** model es la fuente
académica canónica para los conceptos de esta semana:
especialización, generalización, cobertura total/parcial y disyunción exclusiva/inclusiva.
