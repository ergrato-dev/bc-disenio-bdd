# Semana 05 — ER Avanzado

> Herencia, especialización y las herramientas profesionales de modelado

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- ✅ Modelar jerarquías con especialización total/parcial y exclusiva/inclusiva
- ✅ Aplicar el patrón de generalización para abstraer entidades similares
- ✅ Usar dbdiagram.io (DBML) para modelado colaborativo rápido
- ✅ Revisar críticamente un diagrama ER e identificar anti-patrones

## 📋 Prerequisitos

- [ ] Semana 04 — Entidades débiles y relaciones ternarias
