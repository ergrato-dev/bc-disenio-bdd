# Semana 06 — Del ER al modelo relacional

> Transforma tu diagrama conceptual en un modelo de tablas normalizable

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- ✅ Aplicar las 7 reglas de transformación ER → Relacional
- ✅ Mapear entidades fuertes, débiles y asociativas a tablas relacionales
- ✅ Transformar relaciones 1:1, 1:N y N:M con claves foráneas correctas
- ✅ Representar jerarquías de herencia con las estrategias tabla-por-clase, tabla-única y tabla-por-subtipo
