# Videografía — Semana 07: Normalización I

Videos y cursos en video sobre dependencias funcionales, 1FN y 2FN.

---

## Inglés

### 1. CMU Database Systems — Lecture 13: Functional Dependencies

- **URL:** <https://www.youtube.com/watch?v=h5WSf7JaCUk>
- **Canal:** CMU Database Group
- **Duración:** ~1h 20m
- **Nivel:** Universitario / Avanzado
- **Por qué verlo:** Clase magistral de Andy Pavlo (Carnegie Mellon). Cubre la
  teoría formal de dependencias funcionales, axiomas de Armstrong, cierre de
  atributos y formas normales con rigor académico. El estándar de la industria.

### 2. Database Normalization — Caleb Curry (serie completa)

- **URL:** <https://www.youtube.com/playlist?list=PL_c9BZzLwBRK7JpPdTGTNuFKy5F_oYJAP>
- **Canal:** Caleb Curry
- **Duración:** ~45m (5 videos de ~9m)
- **Nivel:** Introductorio
- **Por qué verlo:** La explicación más accesible de normalización en YouTube.
  Usa ejemplos visuales paso a paso. Ideal para ver antes de leer la teoría formal.

### 3. First Normal Form (1NF) Explained — Socratica

- **URL:** <https://www.youtube.com/watch?v=J-drts3N9C8>
- **Canal:** Socratica
- **Duración:** ~8m
- **Nivel:** Introductorio
- **Por qué verlo:** Animación clara de los 3 criterios de 1FN con ejemplos
  concretos. Excelente como repaso rápido antes de un examen.

### 4. Second Normal Form (2NF) — Database Star

- **URL:** <https://www.youtube.com/watch?v=BqjgJgqGEFk>
- **Canal:** Database Star
- **Duración:** ~12m
- **Nivel:** Intermedio
- **Por qué verlo:** Ejemplo detallado de cómo identificar y eliminar dependencias
  parciales. El canal tiene una serie completa de normalización muy bien explicada.

## Español

### 5. Normalización de Bases de Datos — Fazt Code

- **URL:** <https://www.youtube.com/watch?v=GFQaEYEc8_8>
- **Canal:** Fazt Code
- **Duración:** ~35m
- **Nivel:** Introductorio / Intermedio
- **Por qué verlo:** Una de las mejores explicaciones en español de 1FN, 2FN y
  3FN. Usa ejemplos de sistemas web reales y PostgreSQL. Muy recomendado para
  estudiantes hispanohablantes.

### 6. Dependencias Funcionales y Formas Normales — Bases de Datos UNAM

- **URL:** <https://www.youtube.com/watch?v=NZQv3-NBXAE>
- **Canal:** Ingeniería UNAM
- **Duración:** ~50m
- **Nivel:** Universitario
- **Por qué verlo:** Clase completa sobre dependencias funcionales con axiomas
  de Armstrong, cierre de atributos y algoritmo de determinación de claves.
  Rigor académico en español.
