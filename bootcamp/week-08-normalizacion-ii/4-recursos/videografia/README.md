# Videografía — Semana 08: Normalización II

## Videos Recomendados

### 1. CMU Intro to Database Systems — Lecture 13: Functional Dependencies & BCNF

**Canal:** CMU Database Group (Andy Pavlo)  
**URL:** <https://www.youtube.com/watch?v=GuQKU-BPJP8>  
**Duración:** ~75 min  
**Idioma:** Inglés  
**Nivel:** Universitario (accesible)

> La mejor explicación académica de FNBC disponible en YouTube. Pavlo usa el
> ejemplo clásico de horario de clases para mostrar la diferencia entre 3FN y
> FNBC, y discute el trade-off de pérdida de dependencias con rigor pero sin
> exceso de formalidad matemática.

**Momentos clave:**
- min 0–25: Repaso de dependencias funcionales y algoritmo de cierre
- min 25–50: FNBC — definición y detección
- min 50–75: Descomposición y el problema de pérdida de FDs
