# Semana 08 — Normalización II

> 3FN, FNBC y el arte de saber cuándo parar (o cuándo desnormalizar)

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- ✅ Llevar un esquema a Tercera Forma Normal (3FN) eliminando dependencias transitivas
- ✅ Aplicar la Forma Normal de Boyce-Codd (FNBC) cuando hay claves candidatas múltiples
- ✅ Identificar escenarios donde la desnormalización controlada mejora el rendimiento
- ✅ Documentar decisiones de desnormalización con justificación técnica

## 📋 Prerequisitos

- [ ] Semana 07 — 1FN y 2FN dominados
