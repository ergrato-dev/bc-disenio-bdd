# Videografía — Semana 09: Integridad y Restricciones

> Videos recomendados para reforzar conceptos de constraints, integridad
> referencial y diseño de esquemas defensivos en PostgreSQL.

---

## PostgreSQL Constraints Explained — Database Star

| Campo    | Detalle |
|----------|---------|
| Canal    | Database Star |
| URL      | <https://www.youtube.com/watch?v=2kK5DkSTIZc> |
| Duración | ~18 min |
| Idioma   | Inglés |

**Resumen:** Recorre todos los tipos de constraints de PostgreSQL con ejemplos
en pgAdmin. Ideal para ver visualmente qué sucede cuando se viola cada
constraint. Cubre PK, UNIQUE, NOT NULL, FK y CHECK en un solo video.

## Foreign Key Cascade Explained — Hussein Nasser

| Campo    | Detalle |
|----------|---------|
| Canal    | Hussein Nasser |
| URL      | <https://www.youtube.com/watch?v=SXKN8TBCMQA> |
| Duración | ~22 min |
| Idioma   | Inglés |

**Resumen:** Explica en profundidad las políticas ON DELETE (CASCADE, RESTRICT,
SET NULL) con demos en tiempo real. Hussein muestra exactamente qué pasa en
la base de datos para cada opción, y discute los riesgos de usar CASCADE
inadvertidamente en tablas grandes.

| URL      | <https://www.youtube.com/watch?v=d-hvF6N_5mQ> |

| Idioma   | Inglés |
