# Glosario — Semana 10: DDL completo en PostgreSQL

> Términos técnicos introducidos esta semana, ordenados alfabéticamente.

| Término | Definición | Ejemplo |
|---------|------------|---------|
| `BIGSERIAL` | Shorthand legado de PostgreSQL que crea automáticamente una columna `BIGINT` con una secuencia y un `DEFAULT nextval(...)`. Equivalente a `BIGINT GENERATED BY DEFAULT AS IDENTITY` pero no estándar SQL. | `event_id BIGSERIAL PRIMARY KEY` |
| `BOOLEAN` | Tipo de dato para valores lógicos verdadero/falso. Acepta `true`/`false`, `'t'`/`'f'`, `1`/`0` en INSERT. Preferir sobre `SMALLINT` o `VARCHAR` para flags. | `is_active BOOLEAN NOT NULL DEFAULT TRUE` |
| `CHAR(n)` | Tipo de texto de longitud **fija**. Si el valor insertado tiene menos de `n` caracteres, se rellena con espacios. Usar solo cuando la longitud es exactamente `n` (p.ej., códigos ISO). | `country_code CHAR(2) NOT NULL` |
| Columna computada (*computed column*) | Columna cuyo valor se calcula automáticamente a partir de una expresión y se almacena físicamente. Se declara con `GENERATED ALWAYS AS (expresión) STORED`. No puede actualizarse directamente. | `full_price NUMERIC GENERATED ALWAYS AS (price * 1.19) STORED` |
| `CREATE SCHEMA` | Comando DDL que crea un nuevo espacio de nombres (*namespace*) dentro de una base de datos para agrupar objetos (tablas, vistas, funciones, secuencias). | `CREATE SCHEMA IF NOT EXISTS app` |
| `currval()` | Función de PostgreSQL que retorna el último valor generado por una secuencia en la sesión actual. Lanza un error si `nextval()` no ha sido llamado en la sesión. | `SELECT currval('invoice_seq')` |
| `DEFAULT` | Cláusula que define el valor que se usará en una columna cuando el `INSERT` no lo incluye. Puede ser una constante, una función (`NOW()`, `gen_random_uuid()`) o una expresión. | `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()` |
| `DATE` | Tipo de dato para almacenar solo fecha (año, mes, día), sin información de hora ni zona horaria. Ocupa 4 bytes. | `due_date DATE` |
| `gen_random_uuid()` | Función incorporada en PostgreSQL 13+ que genera un UUID v4 aleatorio de 128 bits. No requiere extensión. Función equivalente en versiones anteriores: `uuid_generate_v4()` (requiere `pgcrypto`). | `DEFAULT gen_random_uuid()` |
| `GENERATED ALWAYS AS IDENTITY` | Estándar SQL:2003. El motor siempre genera el valor de la columna; no se puede insertar un valor explícito (excepto con `OVERRIDING SYSTEM VALUE`). Preferible a `SERIAL`. | `task_number BIGINT GENERATED ALWAYS AS IDENTITY` |
| `GENERATED BY DEFAULT AS IDENTITY` | Variante del estándar SQL:2003 donde el motor genera el valor por defecto pero el usuario puede sobreescribirlo con un `INSERT` explícito. Útil en migraciones de datos. | `invoice_number BIGINT GENERATED BY DEFAULT AS IDENTITY` |
| Idempotencia (*idempotency*) | Propiedad de un script que produce el mismo resultado final independientemente de cuántas veces se ejecute. En DDL se logra con `CREATE ... IF NOT EXISTS`, `ADD COLUMN IF NOT EXISTS` y transacciones. | `CREATE TABLE IF NOT EXISTS app.users (...)` |
| `INTERVAL` | Tipo de dato para almacenar duraciones de tiempo (días, horas, minutos, segundos). No almacena un momento específico, sino una cantidad de tiempo. | `session_duration INTERVAL DEFAULT '1 hour'` |
| `JSONB` | Tipo de dato que almacena JSON en formato binario optimizado para consultas y operaciones GIN. Siempre preferir sobre `JSON` salvo que se necesite preservar el orden de las claves. | `user_preferences JSONB DEFAULT '{}'` |
| `nextval()` | Función de PostgreSQL que avanza la secuencia y retorna el nuevo valor. La operación no se puede deshacer con `ROLLBACK` — los huecos en la secuencia son normales. | `SELECT nextval('invoice_seq')` |
| `NUMERIC(p, s)` | Tipo decimal de precisión exacta con `p` dígitos totales y `s` dígitos decimales. Preferir sobre `REAL`/`DOUBLE PRECISION` para valores monetarios porque no tiene errores de redondeo. | `product_price NUMERIC(10, 2) NOT NULL` |
| `OVERRIDING SYSTEM VALUE` | Cláusula de `INSERT` que permite insertar un valor explícito en una columna `GENERATED ALWAYS AS IDENTITY`, saltando la restricción del motor. Útil en scripts de migración. | `INSERT INTO tasks (task_number) VALUES (99) OVERRIDING SYSTEM VALUE` |
| `search_path` | Parámetro de configuración de PostgreSQL que define el orden en que se buscan los schemas cuando se usa un nombre no calificado. Equivalente al PATH del sistema operativo, pero para objetos de BD. | `SET search_path = app, public` |
| Secuencia (*sequence*) | Objeto de la base de datos que genera enteros únicos y crecientes. Base de los mecanismos `SERIAL` e `IDENTITY`. Puede crearse de forma independiente con `CREATE SEQUENCE`. | `CREATE SEQUENCE invoice_seq START WITH 1000` |
| `SERIAL` | Shorthand legado de PostgreSQL que crea una columna `INTEGER` con una secuencia y un `DEFAULT nextval(...)`. No es estándar SQL. Reemplazado por `GENERATED AS IDENTITY`. | `id SERIAL PRIMARY KEY` |
| `setval()` | Función que establece el valor actual de una secuencia. Segundo parámetro `false` hace que el próximo `nextval()` retorne exactamente ese valor; `true` (por defecto) lo incrementa. | `SELECT setval('invoice_seq', 5000)` |
| `SMALLINT` | Entero de 2 bytes con rango −32 768 a 32 767. Usar para columnas con valores pequeños y acotados: prioridades, calificaciones, cantidades pequeñas. | `review_rating SMALLINT NOT NULL CHECK (review_rating BETWEEN 1 AND 5)` |
| `TEXT` | Tipo de texto de longitud variable sin límite explícito. Equivalente a `VARCHAR` sin restricción de longitud. Usar para descripciones, cuerpos de mensajes y contenido de longitud arbitraria. | `task_description TEXT` |
| `TIMESTAMPTZ` | Tipo de dato que almacena fecha y hora **con zona horaria** (internamente en UTC). Siempre preferir sobre `TIMESTAMP` para eventos y auditoría. | `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()` |
| `UUID` | Tipo de dato de 128 bits que almacena identificadores únicos universales. En PostgreSQL se genera con `gen_random_uuid()`. Recomendado como PK para entidades internas. | `user_id UUID NOT NULL DEFAULT gen_random_uuid()` |
| `VARCHAR(n)` | Tipo de texto de longitud variable con un máximo de `n` caracteres. Equivalente a `TEXT` con una restricción `CHECK (length(...) <= n)`. Usar cuando la longitud máxima es conocida y razonable. | `user_email VARCHAR(150) NOT NULL` |
