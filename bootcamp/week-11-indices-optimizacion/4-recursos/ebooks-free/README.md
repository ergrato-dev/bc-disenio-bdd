# Libros Gratuitos — Semana 11: Índices y Optimización

## Documentación Oficial (Gratis)

| Recurso | URL | Por qué leerlo |
|---------|-----|----------------|
| PostgreSQL 16 — Capítulo 11: Indexes | https://www.postgresql.org/docs/16/indexes.html | Referencia definitiva de todos los tipos de índice en PG16, opciones de `CREATE INDEX` y casos de uso |
| PostgreSQL 16 — EXPLAIN | https://www.postgresql.org/docs/16/sql-explain.html | Sintaxis completa de `EXPLAIN` y todas las opciones (`ANALYZE`, `BUFFERS`, `FORMAT JSON`) |
| PostgreSQL 16 — Capítulo 14: Performance Tips | https://www.postgresql.org/docs/16/performance-tips.html | Guía oficial de optimización: `EXPLAIN`, estadísticas del planificador, configuración de `work_mem` y `effective_cache_size` |
| PostgreSQL 16 — Using EXPLAIN | https://www.postgresql.org/docs/16/using-explain.html | Tutorial detallado sobre cómo leer el plan de ejecución paso a paso |

## Libros Gratuitos Online

| Libro | URL | Por qué leerlo |
|-------|-----|----------------|
| **Use The Index, Luke** — Markus Winand | https://use-the-index-luke.com/ | El recurso más completo y práctico sobre indexación SQL. Explica B-tree desde cero, selectividad, índices compuestos y cuando el planificador los ignora. Totalmente gratis online |
| **The Internals of PostgreSQL** — Hironobu Suzuki (Capítulo 1 y 9) | https://www.interdb.jp/pg/ | Explica cómo PostgreSQL almacena datos en páginas y cómo funciona internamente el índice B-tree. Ideal para entender los `ctid` y el heap |
