# Semana 12 — Objetos avanzados y transacciones

> Vistas, funciones, triggers y ACID: la capa de lógica en la base de datos

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- ✅ Crear vistas simples y materializadas para encapsular consultas complejas
- ✅ Escribir funciones en PL/pgSQL para lógica de negocio encapsulada en BD
- ✅ Implementar triggers `BEFORE`/`AFTER` para auditoría y consistencia automática
- ✅ Gestionar transacciones con `BEGIN`, `COMMIT`, `ROLLBACK` y `SAVEPOINT`

## 📋 Prerequisitos

- [ ] Semana 11 — Índices y lectura de `EXPLAIN ANALYZE`
