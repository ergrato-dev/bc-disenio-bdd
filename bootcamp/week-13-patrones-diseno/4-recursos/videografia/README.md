## Row Level Security y Multi-Tenancy

### Row Level Security in PostgreSQL
- **Canal:** Supabase
- **URL:** <https://www.youtube.com/watch?v=Ow_Uzedfohk>
- **Duración:** ~20 min
- **Idioma:** Inglés
- **Por qué:** Demostración práctica de RLS con `CREATE POLICY` en un proyecto
  real. El contexto es Supabase pero los conceptos son 100% PostgreSQL estándar.

### Multi-Tenant SaaS Database Design
- **Canal:** CMU Database Group
- **URL:** <https://www.youtube.com/watch?v=ixpQnMz7RIc>
- **Duración:** ~45 min
- **Idioma:** Inglés
- **Por qué:** Conferencia académica que compara las 3 estrategias de
  multi-tenancy (database-per-tenant, schema-per-tenant, shared tables).
  Incluye análisis de costos y casos de uso reales.
