# Videografía Recomendada — Semana 14

Videos y cursos en línea para consolidar los conceptos del bootcamp
y explorar temas avanzados de bases de datos.

---

## Fundamentos y Diseño de BD

### CMU 15-445: Intro to Database Systems (Andy Pavlo)
- **URL:** https://www.youtube.com/playlist?list=PLSE8ODhjZXjbj8BMuIrRcacnQh20hmY9g
- **Duración:** ~40 horas (curso completo, 25 clases)
- **Idioma:** Inglés
- **Por qué:** El mejor curso universitario de bases de datos disponible
  gratuitamente. Cubre modelos de datos, almacenamiento, indexación,
  query processing, transacciones y concurrencia. Las clases 1-6 son un
  repaso perfecto de los conceptos del bootcamp.

### Database Design Course (freeCodeCamp / Caleb Curry)
- **URL:** https://www.youtube.com/watch?v=ztHopE5Wnpc
- **Duración:** 8 horas
- **Idioma:** Inglés
- **Por qué:** Curso completo de diseño de bases de datos relacionales
  desde cero: diagramas ER, normalización, modelo físico. Excelente
  para repasar el pipeline completo antes del proyecto final.

## PostgreSQL

### PostgreSQL Full Course (Hussein Nasser)
- **URL:** https://www.youtube.com/watch?v=qw--VYLpxG4
- **Duración:** 4.5 horas
- **Idioma:** Inglés
- **Por qué:** Recorre PostgreSQL desde la instalación hasta índices,
  transacciones y performance. Hussein explica con claridad los
  internals relevantes para tomar decisiones de diseño.

### PostgreSQL Crash Course (Traversy Media)
- **URL:** https://www.youtube.com/watch?v=qw--VYLpxG4
- **Duración:** 1.5 horas
- **Idioma:** Inglés
- **Por qué:** Ideal como repaso rápido de DDL, DML y funciones básicas
  antes de comenzar el proyecto final.

## Optimización y Performance

### Explaining the Postgres Query Planner (Laurenz Albe — pgDay)
- **URL:** https://www.youtube.com/results?search_query=laurenz+albe+query+planner
- **Duración:** ~50 minutos
- **Idioma:** Inglés
- **Por qué:** Explica cómo leer `EXPLAIN ANALYZE` de forma práctica,
  qué significan cada tipo de scan y cuándo los índices no se usan.

### Indexing Strategies in PostgreSQL (PGCon talks)
- **URL:** https://www.youtube.com/results?search_query=pgcon+indexing+postgresql
- **Duración:** ~1 hora
- **Idioma:** Inglés
- **Por qué:** Estrategias de indexación avanzadas: índices parciales,
  GIN, índices compuestos, índices de expresión. Directamente aplicable
  al RF-06 del proyecto MediSync.

## Patrones Avanzados

### Multi-Tenancy with PostgreSQL Row Level Security (Crunchy Data)
- **URL:** https://www.youtube.com/results?search_query=postgresql+row+level+security+multitenancy
- **Duración:** ~45 minutos
- **Idioma:** Inglés
- **Por qué:** Explica el modelo de RLS, cómo crear políticas, y cómo
  estructurar aplicaciones multi-tenant. Aplica directamente al patrón
