# Semana 14 — Proyecto Final Integrador

> De los requerimientos al DDL: demuestra que puedes diseñar una BD de producción

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- ✅ Analizar requerimientos de negocio complejos y extraer entidades y relaciones
- ✅ Producir un modelo conceptual (ER), lógico (DBML) y físico (DDL) coherentes entre sí
- ✅ Justificar cada decisión de diseño con criterios técnicos documentados
- ✅ Entregar un proyecto de base de datos completo y listo para producción
