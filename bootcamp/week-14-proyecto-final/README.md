# Semana 14 — Proyecto Final Integrador

> De los requerimientos al DDL: demuestra que puedes diseñar una BD de producción

## Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- Recorrer el pipeline completo de diseño: análisis → ER conceptual → modelo lógico → DDL físico → índices → patrones avanzados
- Aplicar el checklist de calidad para auditar cualquier diseño de base de datos
- Identificar y corregir anti-patrones comunes en esquemas reales
- Documentar y presentar decisiones de diseño con justificación técnica
- Entregar un proyecto integrador que demuestre todas las competencias del bootcamp

## Prerequisitos

- Semanas 01–13 — Bootcamp completo

## Entregables del Proyecto Final

- Diagrama ER en draw.io exportado como SVG (modelo conceptual)
- Modelo DBML en dbdiagram.io (modelo lógico)
- Script DDL completo e idempotente (modelo físico en PostgreSQL 16+)
- Estrategia de indexación con justificación en comentarios SQL
- Mínimo 2 objetos avanzados: vista + función o trigger
- Mínimo 1 patrón de diseño avanzado: soft delete, auditoría o jerarquía
